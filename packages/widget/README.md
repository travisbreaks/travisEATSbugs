# @travisbreaks/travisEATSbugs

Drop-in visual-feedback widget for any web app.

```bash
pnpm add @travisbreaks/travisEATSbugs
```

```ts
import { init } from '@travisbreaks/travisEATSbugs'

init({ project: 'YOUR_PROJECT_TOKEN' })
```
